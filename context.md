# Project Context: THOURAM

> **THOURAM** — Community Volunteer Event Platform rooted in Manipuri heritage and collective collaboration.

## Project Vision

- **Working title:** THOURAM
- **One-sentence vision:** A purpose-built community volunteer event platform enabling transparent duty matching, automated backup waitlists, encrypted QR attendance, and verified impact logging.
- **Target users:** Community organizers, civic NGOs, volunteer coordinators, sub-managers, and community volunteers.
- **Core problem:** Volunteer drop-offs, disorganized rosters, unverified service hours, and lack of transparent matching.
- **Desired outcome:** Reliable volunteer turnout with automated 10% backup promotions, frictionless check-in, and reliable impact measurement.

## Success Criteria & Implemented Highlights

- [x] Exact reproduction of the Stitch Design System UI (typography, color palettes, spacing, emblem, and responsive layouts).
- [x] Transparent algorithmic match scoring (Skills 40%, Proximity 20%, Interests 20%, Reliability 20%).
- [x] Automated 10% standby backup calculation and auto-promotion workflow upon volunteer withdrawal.
- [x] Dynamic encrypted QR code event passes and on-site scanner simulation.
- [x] Dual-score post-event ratings (separate Reliability/Completion and Work Quality scores) with verified service hours accumulation.
- [x] Scoped role delegation (Organizer, Sub-Manager, Team Lead, Volunteer) with audit logs.
- [x] Seeded database containing 55+ demo volunteers, Loktak Lake flagship event (50 confirmed + 5 backups), and closeout records.
